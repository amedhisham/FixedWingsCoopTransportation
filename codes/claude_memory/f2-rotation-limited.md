**DECISIVE 2026-09-12: the F2 2-traj DET_R≈-0.39 plateau is a ROTATION-LIMITED slow crawl along a linearly-connected descent — NOT a batch, LR, or noise wall.** This corrects [[f2-noise-limited]] (the "critical batch = millions / GPU now necessary" claim was estimator breakdown at 92k). The 2-traj MIX (+x+y+z / +x+y-z) is the same one that's provably reachable to ~-0.39 ([[f2-mix-curriculum]]).

**THE SUPERCRITICAL RERUN (1.4M batch, 94-core cluster node, log_std FROZEN so gradients are mean-only):** critB EMA ≈ 300–700k (clean, EMA≈raw, no `nan`), **gcos ≈ 0.6–0.8** — the mean gradient is COHERENT, not noise-thrash. So NOT noise-limited: the batch is ~2–4× supercritical and bigger batch cannot help (it sharpens `E[g]`, doesn't shrink the noise that's already resolved). Yet DET_R barely moves. Key reconciliation of "coherent gradient + flat return": a high gcos measures gradient SELF-CONSISTENCY (direction), NOT alignment with DET_R improvement. And a coherent field that never improves is PROOF it's not the gradient of a fixed scalar — because exact ∇J(fixed) + coherent steps MUST descend (Adam decouples step size from ‖g‖, so 100+ coherent iters would move a real slope). The cause: on-policy actor-CRITIC is a coupled dynamical system whose update field is NON-CONSERVATIVE (has curl → orbits), per Balduzzi et al. 2018 "The Mechanics of n-Player Differentiable Games" (potential + Hamiltonian/rotational decomposition). Ruled OUT as the cause: batch/noise (supercritical, gcos high), advantage bias (adv mean-centered, line 562), aux-loss tug-of-war (CONSIST_W=CONSIST_LAM_W=0), entropy coef (Gaussian entropy depends only on log_std → 0 gradient to the mean; ENT_COEF inert, doubly so when frozen).

**ROTATION DIAGNOSTICS ADDED to mappo.py (per-iter print):**
- `gnorm` = ‖g_full‖ (full-batch mean-grad magnitude; already computed for critB). Small+stable (~0.12–0.24, well under clip MAX_GRAD=1.0) → not a large-gradient overshoot in ‖g‖ terms.
- `gcos@1/2/4/8` = mean-grad cosine at LAGS 1/2/4/8. Measured: ~0.6 @1, ~0.5 @2, ~0.3 @4, **~0/negative @8** → coherence is LOCAL (consecutive iters agree) but dies over an ~8-iter scale = the rotation PERIOD.
- `R` = cumulative coherence ratio ‖Σ_t g_t‖ / Σ_t‖g_t‖ over the run. Decayed **0.84 → 0.34** over ~40 iters → steps CANCEL: net displacement is ~1/3 of path length (spiral, not translation). R~1 would = pure translation; R~0 = pure circle. 0.34 = a SPIRAL (real net drift + big rotational cancellation).
- `FREEZE_LOG_STD` flag: pins log_std (requires_grad=False) at σ=0.32 (ent≈2.79) so the WHOLE actor gradient is the MEAN direction (gcos/critB/gnorm skip grad=None params → mean-only). Froze gcos dropped 0.8→0.67 → part of the old 0.8 WAS log_std annealing coherence. Entropy math (corrected in code comments): H = act_dim·(0.5·ln(2πe)+log_std) = 10·(1.4189+log_std); act_dim=10 (dlam n=4 + dwrench 6); σ=0.32→ent 2.79 (old "~2.6 at σ≥0.25" comments were WRONG — σ=0.25→ent 0.33).

**DET_R SHAPE over the spiral:** flat ~-0.391 for the first ~44 iters, THEN slowly climbs to a new best -0.383 by ~iter 56 (a slowly-DESCENDING spiral, not a flat orbit at the optimum — an earlier over-call was corrected).

**THE DECISIVE TEST — CHECKPOINT-INTERPOLATION LINE-SEARCH (interp_search.py; the ONLY valid line-search here):** interpolate between the two REAL endpoints of the actual spiral — θ_A = residual_mappo_overfit_xyz_2trj_ch.pt (-0.392) and θ_B = residual_mappo_overfit.pt (-0.383) — d = θ_B−θ_A = the FULL 56-iter net drift, for free. Eval DET_R at θ_A + α·d (uses θ_A's obs-norm; both 2-traj → norms ~identical, α=1 reproduces B within 0.001). RESULT: α=0 -0.3924, **0.75 -0.3797 (BEST, beats BOTH endpoints)**, 1.0 -0.3850 (=B), then degrades (2.0 -0.413, 3.0 -0.495). So: (1) NO barrier — A and B are LINEARLY CONNECTED (same basin); the winding route was unnecessary. (2) The straight line reaches a BETTER point (-0.380) than the spiral's own endpoint (-0.385), at 0.75× the displacement. (3) The spiral OVERSHOT: ‖θ_B−θ_A‖=30.5 but with R≈0.34 the actual weight-space PATH was ~90 — ~4× the travel for a worse result. **This is the rotation tax, measured end-to-end.**

**THE FRESH-GRADIENT LINE-SEARCH (linesearch.py, cluster, from -0.392, K=3 iters, 1.4M/iter) FAILED — and WHY it fails is informative:** both d_net (3-iter net) and d_inst (1-iter) only HARM (best = α=0; α=1 already worse than α=0.5). Because 3 iters captures only the EARLY DOWN-WANDER phase (descent doesn't start until ~iter 44), so extrapolating it extrapolates the wandering. Confirms: (a) K=3 is hopelessly too few — you need tens of iters to average rotation into descent, i.e. the interpolation (real 56-iter endpoint) was the only valid probe; (b) the real training step (α=1) OVERSHOOTS the flat region (α=1 worse than α=0.5) → the LR/step is too big for this rotational field ("moving too much harms").
